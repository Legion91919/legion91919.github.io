# Portfolio site

Source of [legion91919.github.io](https://legion91919.github.io): thirteen systems, the architecture each one got, and why.

- `index.html` is self-contained (one file, no build step); project data is inlined from arch-advisor `compare` runs.
- `shots/` holds screenshots of each project's chosen screen design.
- `fonts/` holds Schibsted Grotesk (SIL Open Font License, see `fonts/OFL.txt`).

All companies, people and figures in the projects are invented.
