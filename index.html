How I work

I set up the agents before they write code. Each project carries a hidden folder of context that every agent reads and updates, and nothing is built until the problem, the decision and the screens exist.

  1. FrameOne sentence for the problem, the risks ranked, the first demo named.
  2. MapUsers, data and failure modes, with evidence for every architecture trait.
  3. DecideThe advisor's comparison, an ADR with the options I turned down, and a design dossier.
  4. SketchThree genuinely different screen designs, scored, one chosen with all four states.
  5. Build in slicesA failing acceptance test first, then code, then a demo. One slice at a time.
  6. Hand overRunbook, owned secrets and the agent setup itself, checked by a readiness score.
